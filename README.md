# RIFTBLADE · 파열검

차원의 균열에서 쏟아지는 그림자 군세를 베어내는 **2D 벨트스크롤 액션**.
던전 파이터류 장르·전투의 손맛을 참고하되 세계관·캐릭터·명칭·그래픽·스킬·연출·사운드는 **전부 독자 제작**이며, 모든 에셋은 외부 이미지 없이 **캔버스 코드로 프로시저럴 생성**했다.

> Fable 5 · "원 프롬프트로 어느 정도 완성도의 게임이 나오는가" 테스트로 제작.

## 실행 (PC 브라우저)

## 조작

| 동작 | 키 |
|------|----|
| 이동 | ← → ↑ ↓ (또는 WASD) — ↑↓는 위/아래 깊이 이동 |
| 공격 | J (4연타 콤보) |
| 어퍼(띄우기) | ↓ + J → 적을 공중에 띄움 |
| 공중 콤보 | 점프(K/Space) + J, 공중에서 ↓+J = 내려찍기 |
| 대시(무적) | L / Shift |
| 스킬 | U 파열참 · I 천공참 · O 파열노바 (MP 소모·쿨다운) |
| 일시정지 | P |

**연계 예시:** `↓+J(어퍼)` → `K(점프)` → `J J(공중 콤보)` → `↓+J(내려찍기)` → 착지 후 `O(노바)`.

## 특징

- **손맛/연출**: 히트스톱, 화면 흔들림, 피격 백색 플래시, 참격 아크, 스파크·파편, 데미지 숫자, 콤보 카운터.
- **벨트스크롤**: 좌우 + 상하 깊이(z) 이동, 원근 스케일·그림자, 카메라 추적.
- **적**: 그림자 졸개 / 돌격병(돌진) / 저주술사(원거리) / **보스 균열 감시자**(체력 50% 페이즈 전환).
- **웨이브**: 10개 균열이 한 주기, 10웨이브에 보스 강림. 클리어해도 끝나지 않고 다음 주기가 더 강하게 반복되는 무한 모드 (웨이브·주기마다 적 체력/공격력 스케일링).
- **사운드**: WebAudio 절차적 효과음(외부 파일 0개).

## 구조

```
src/core/   엔진 — util(좌표/수학) · input(키) · audio(절차적 SFX) · particles · camera(추적/흔들림)
src/game/   fighter(물리/피격/히트박스 베이스) · player(콤보/어퍼/공중/대시/스킬)
            enemy(AI·보스) · world(오케스트레이션·히트판정·히트스톱·웨이브) · render(프로시저럴 아트) · hud
src/main.ts 루프(고정 타임스텝) + 상태(타이틀/플레이/승패)
```
